# VFC — Windows 视频格式转换器

基于 **Qt 6 + C++** 开发的 Windows 桌面视频格式转换器，转换能力由 **FFmpeg** 提供。
界面使用 Qt Widgets 以纯代码构建（无 `.ui` 文件），所有外部进程异步执行，转换全程界面不阻塞。

## 功能

### 视频信息探测

打开视频后自动调用 `ffprobe`（媒体信息探测工具）读取并展示 10 项信息：
时长、文件大小、容器格式、分辨率、像素格式、视频编码、帧率、码率、音频编码、音频参数。
信息区支持**双列自动分栏**：窗口变小时自动拆为两列，窗口变大时自动合并为单列，始终与缩略图等高对齐。

### 缩略图预览

- 抽取视频第 1 秒的一帧（时长不足 1 秒时取第 0 秒）作为预览图；
- 抽帧保留**原始分辨率**，显示时按 16:9 自适应缩放，配合 `devicePixelRatioF()`（设备像素比）在 150% 等高 DPI 缩放下依然清晰；
- 竖屏视频保持比例、正确留边；损坏文件给出明确提示，不崩溃。

### 格式转换

- 输出格式：**MP4 / MKV / MOV / AVI**
- 质量档位：高 / 中 / 低（对应 CRF 18 / 23 / 28）
- 编码参数：H.264（libx264）+ AAC（AVI 容器改用 MP3），`-pix_fmt yuv420p` 保证播放兼容性，MP4 / MOV 追加 `+faststart`（元数据前置，便于网络播放）
- 输出文件自动加 `_converted` 后缀；同名文件自动避让（`_1`、`_2`……），**从不覆盖已有文件**

### 进度与状态

- 解析 ffmpeg 的 `-progress pipe:1` 输出，读取 `out_time_us`（已处理时长，微秒）计算进度；
- 结合 `speed=`（速度因子）与 50 ms 定时器做外推平滑，进度条不跳变；
- **操作日志面板**记录全流程（探测 → 抽帧 → 转换 → 完成 / 失败原因），支持一键清空。

### 健壮性设计

- 转换先写入 `<名称>.part.<扩展名>` 临时文件，成功后改名为成品，失败 / 取消 / 退出时清理——**输出目录不会残留半成品**；
- 所有外部进程使用 `QProcess`（Qt 的进程类）异步启动，界面全程不阻塞；用 `jobId`（任务编号）+ 断开信号双保险，避免快速连续操作时旧任务回调串写；
- 转换完成后可直接在资源管理器中定位成品文件。

## 技术栈

| ---- | -------------------------------------- |
| 语言 | C++17                                  |

## 目录结构

```
VFC/
├── CMakeLists.txt          # 构建脚本，条件编译自测模块
├── main.cpp                # 程序入口，处理 --selftest
├── mainwindow.h/.cpp       # 主窗口、信息探测、缩略图、转换与进度
├── selftest.h/.cpp         # 程序化自测（可选模块）
├── package.cmd             # Windows 一键打包脚本
├── docs/                   # 界面截图
└── README.md
```

## 构建

1. 用 Qt Creator 打开 `CMakeLists.txt`，选择 **Qt 6.8.2 MSVC 2022 64bit** 套件；
2. 选择 Release 配置，执行「构建 → 重新构建项目」；
3. 产物位于 `build/<套件名>-Release/VFC.exe`。

> 修改 `CMakeLists.txt` 后必须重新执行一次 CMake，否则自测模块的宏不会生效。

## 运行

程序会自动查找 FFmpeg：程序目录（含 `ffmpeg/bin/`、`tools/`）→ 系统 PATH → 注册表 Path → WinGet 安装目录。
若未找到，也可把 `ffmpeg.exe` / `ffprobe.exe` 放在 `VFC.exe` 同级目录。

## 程序化自测

```cmd
VFC.exe --selftest
```

自测覆盖 6 项用例：

1. 单独打开正常视频（信息 + 缩略图）
2. 打开损坏文件（应被拒绝且不崩溃）
3. 打开含中文与空格文件名的视频
4. 快速连续切换视频（验证任务防串扰）
5. 完整转换一次（验证产物可生成、临时文件被清理）
6. 转换中途取消（验证不留残缺文件）

设计要点：

- **素材内置生成**：测试视频由程序调用 ffmpeg 现场生成（含中文名、损坏文件、长片），不依赖任何本机素材；
- **环境隔离**：素材与输出都写入系统临时目录，跑完自动清理，可反复运行；
- **结果可追溯**：结果同时输出到 Qt Creator 的「应用程序输出」面板与同目录 `selftest_result.txt`。

## 打包发布

```cmd
package.cmd
```

脚本自动完成：定位 Release 版 `VFC.exe` → `windeployqt`（Qt 部署工具）拷贝运行库 → 随包携带 `ffmpeg.exe` / `ffprobe.exe` → 生成 `dist/VFC-<版本>-win64.zip`。

验证「解压即用」：把解压目录拷到任意位置，临时清空 PATH 后运行 `VFC.exe --selftest`，若 6 项仍通过，说明使用的是随包自带的 FFmpeg。

## 主要优化点

| 优化点           | 说明                                                 |
| ---------------- | ---------------------------------------------------- |
| 全程异步不阻塞   | 所有 ffmpeg / ffprobe 调用异步执行，取消操作立即响应 |
| 任务防串扰       | `jobId` 递增 + 断开信号，旧任务的回调不会写回新文件  |
| 临时文件原子改名 | 写 `.part.<ext>` 后改名，避免半成品污染输出目录      |
| 唯一文件名避让   | 自动递增 `_1`、`_2`，永不覆盖用户已有文件            |
| 进度外推平滑     | `out_time_us` + `speed=` 外推 + 50 ms 定时器         |
| 高 DPI 缩略图    | 抽帧保留原始分辨率 + 设备像素比缩放                  |
| 布局自适应       | 缩略图保持 16:9，信息区双列自动分栏，窗口尺寸记忆    |
| 内置自测         | 6 项用例、素材自动生成、零外部依赖                   |
| 一键打包         | `package.cmd` 可复现地生成可分发包                   |

## 已知限制

- 仅支持单个视频依次转换，未实现批量队列；
- 未启用硬件加速编码（NVENC / QSV）；
- 多音轨 / 字幕流暂不支持选择，默认取第一条视频流与第一条音频流。
